# Google Apps Script backend

Deploy this folder as a Google Apps Script project.

## Suggested sheets
- Users
- Matches
- Predictions
- SpecialQuestions
- SpecialQuestionResponses
- Leaderboard

## Deployment
1. Create a new Apps Script project.
2. Copy the contents of Code.gs into the script editor.
3. Deploy as a Web App.
4. Update the frontend API endpoint in your app once you wire up the real backend.
